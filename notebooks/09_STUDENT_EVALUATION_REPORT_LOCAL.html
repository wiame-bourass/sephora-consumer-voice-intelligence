09 — Student Model Evaluation Report (Local)¶

Notebook local VS Code/Jupyter. Il ne réentraîne aucun modèle.

Il :

  • recharge les students V2 ;
  • recrée le même split test ;
  • calcule les métriques Aspect et Sentiment ;
  • affiche les matrices de confusion ;
  • affiche les plots Precision / Recall / F1 ;
  • compare V1 vs V2 ;
  • analyse les erreurs ;
  • mesure la vitesse locale.

Les métriques mesurent la fidélité aux pseudo-labels GPT-OSS 20B.

def make_multilabel_matrix(df):
    y = np.zeros((len(df), len(ASPECTS)), dtype=int)
    for row_idx, segment_id in enumerate(df["segment_id"]):
        for aspect in segment_aspects.get(segment_id, []):
            if aspect in ASPECTS:

    return y

aspect_tokenizer = AutoTokenizer.from_pretrained(ASPECT_MODEL_DIR)
aspect_model = AutoModelForSequenceClassification.from_pretrained(
    ASPECT_MODEL_DIR
).to(DEVICE)
aspect_model.eval()

texts = test_sample["segment_text"].astype(str).tolist()
BATCH_SIZE = 32
all_probs = []

for start in range(0, len(texts), BATCH_SIZE):
    batch_texts = texts[start:start+BATCH_SIZE]
    enc = aspect_tokenizer(
        batch_texts,
        padding=True,
        truncation=True,
        max_length=160,
        return_tensors="pt",
        return_token_type_ids=False,
    )
    enc = {k: v.to(DEVICE) for k, v in enc.items()}

    with torch.no_grad():
        logits = aspect_model(**enc).logits

    all_probs.append(torch.sigmoid(logits).cpu().numpy())

y_prob_aspect = np.vstack(all_probs)
y_pred_aspect = (y_prob_aspect >= thresholds[None, :]).astype(int)

print("Predictions :", y_pred_aspect.shape)

    SENT_MODEL_DIR
).to(DEVICE)

        batch_texts,

        return_tensors="pt",

    enc = {
