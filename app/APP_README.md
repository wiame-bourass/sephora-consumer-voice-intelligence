# Streamlit demo

This folder contains the interactive demo for the project.

The app uses the saved **DistilBERT V2 models** and does not call GPT-OSS 20B.

## What the app does

- analyze a skincare review entered by the user;
- detect one or more ABSA aspects;
- predict sentiment for each detected aspect;
- display a few consumer-insight aggregations produced by the pipeline.

## Run

From the project root:

```bash
streamlit run app/streamlit_app.py
```

The app expects:
- the saved V2 model artifacts under `artifacts/`;
- the processed business tables generated by the aggregation notebook.

For the full project description, see the root `README.md`.
